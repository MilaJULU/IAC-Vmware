\# IAC - Creación Automatizada de Máquinas Virtuales



\## Descripción



Proyecto de Infraestructura como Código (IaC) para automatizar la creación y configuración de máquinas virtuales mediante un script de línea de comandos.



El script permite definir parámetros como nombre de la máquina virtual, CPU, memoria RAM, tamaño del disco, red, ISO de instalación y directorio de trabajo.



\## Objetivo



Automatizar la creación de máquinas virtuales mediante parámetros configurables, incorporando validaciones de entrada, simulación de ejecución y control de recreación de máquinas existentes.



\## Requisitos



\- Windows 10/11

\- Oracle VirtualBox 7.x

\- PowerShell

\- VBoxManage.exe
